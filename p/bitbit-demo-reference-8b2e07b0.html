Elevator pitch

BitBit is a modular AI operations platform that gives small businesses an always-on, industry-specific personal assistant. Businesses text it on WhatsApp, send voice notes, or use the dashboard. BitBit autonomously handles leads, invoices, client comms, proposals, and more through specialised AI agents that snap together like lego bricks. It replaces $200+/month in SaaS tools (HubSpot, Front, Asana, etc.) with a single intelligent system that learns the business and gets smarter over time

Agent catalog

All 11 agents use the 3-tier model router for cost-optimal inference. Confidence routing: ≥85% auto-act / 55 to 85% ask human / <55% escalate

Routing and triage

  • Channel Triage – Classifies incoming messages, routes to correct agent or human. Haiku 70%/Sonnet 30%. ~$20/mo Built
  • Lead Swarm – Discovers leads, scores them, sends auto-acknowledgments. Sub-2-minute response target. Haiku + Sonnet. ~$50/mo Built
  • Sentry Monitor – Background monitoring, alert escalation, watch management. Runs every 5 min. Haiku. ~$10/mo Built
  • Scheduler – Orchestrates all agent execution, manages task queue. Runs every minute. System. Included Built

Operations and delivery

  • Invoice Flow – Natural language creation, PDF gen, email send. Duplicate detection, Stripe payment links. Haiku + Sonnet. ~$10/mo Built
  • Client Comms (PA) – Drafts client responses with voice matching and relationship context. 12 tools, agentic loop. Sonnet. ~$20 to 40/mo Built
  • Client Onboarding – Auto Asana project creation, welcome emails, credential requests. Sonnet + Haiku. ~$30 to 40/mo Built

Content and proposals

  • Proposal Bot – Generates tiered proposals from briefs, PDF output. Status tracking: draft, sent, viewed, accepted, declined. Opus + Sonnet. ~$30 to 40/mo Built
  • Ad Script Gen – Video/social ad scripts, hook variations, platform-adapted. Reels 15s, TikTok 30s, Shorts 60s, Feed 15 to 30s. Opus + Sonnet. ~$30/mo Built

Intelligence and search

  • AI Search Optimiser – Audits AI visibility across ChatGPT, Gemini, Perplexity, Claude. First-mover advantage, $2k/mo service opportunity. Sonnet + Haiku. ~$20/mo Built
  • Tender Hunter – Scrapes AusTender + state portals, compliance checking, fit scoring. Response draft generation. 99%+ margin vs tender consultants. Opus + Sonnet + Haiku. ~$1 to 2k/mo Built

Confidence routing (the innovation)

≥85% confidence: Auto-execute (fast, no human needed)

55 to 85% confidence: Queue for approval (human decides)

<55% confidence: Escalate immediately (alert the owner)

Thresholds configurable per-agent and per-org. This is what separates BitBit from competitors. It knows WHEN to act vs. when to ask. Most AI tools either auto-do everything (dangerous) or require approval for everything (defeats the purpose)

Objection handling

Objection Response
"How is this different from ChatGPT?" ChatGPT does not know your business. BitBit has a semantic memory layer that learns your contacts, projects, rates, and communication style. It connects to 20 channels and takes real actions (sends invoices, responds to leads, files proposals)
"What about Lindy / other AI assistants?" They are generic. BitBit has industry-specific agent bundles that snap in per vertical. The confidence routing means it knows when to act vs. when to ask. Most competitors either auto-do everything (dangerous) or require approval for everything (slow)
"Is it actually reliable?" Confidence routing: ≥85% auto-act, 55 to 85% ask first, <55% escalate. Circuit breaker, dead letter queue, cost guard, duplicate detection. 719 tests across 51 files. Production-grade reliability
"Why would I switch from my current tools?" "If we make them so reliant on our service because it does literally everything... it's going to be so difficult for them to leave." Consolidation play. One system instead of six

Technical architecture

The stack

Next.js 16 React 19 Supabase Anthropic Claude Pinecone Voyage AI Resend Stripe Sentry Vercel Fly.io Cloudflare

Frontend: Next.js 16 + React 19 (single-page app, lazy-loaded tabs). Backend: 204 API endpoints (Next.js serverless on Vercel). Database: Supabase (Postgres), 118 migrations, full row-level security. AI Engine: Anthropic Claude (3-tier model routing). Search: Pinecone (vector store) + Voyage AI (embeddings). Payments: Stripe (4-tier subscription billing). Hosting: Vercel (dashboard) + Fly.io (workers) + Cloudflare (edge cron)
